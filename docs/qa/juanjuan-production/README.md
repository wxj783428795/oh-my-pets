# 卷卷正式宠物包视觉 QA

本目录保存 Issue 06 可提交、可复核的视觉证据：

- `contact-sheet.png`：15 个动作、86 帧的逐帧接触表，每行一个动作。
- `motion-preview.gif`：按清单时长连续播放全部动作。
- `rare-1.gif`：扑纸、揉成纸团、得意坐住的独立叙事片段。
- `rare-2.gif`：滑倒、挂边、重新探头的独立叙事片段。

接触表和 GIF 均由 `scripts/assemble-production-juanjuan.py` 从与正式图集相同的
清理后帧确定性生成。它们是审阅证据，不被应用运行时加载。

人工审阅时逐项确认：

1. 橘白短腿猫的圆头、猫耳、粗卷尾、深棕轮廓和青色项圈跨动作保持一致；
2. `walk_left` 与 `walk_right` 朝向相反，步态能从轮廓辨认；
3. 循环动作首尾没有明显抽动，非循环动作停在自然结果帧；
4. `rare_1` 和 `rare_2` 在不看动作名时仍能读懂事件顺序；
5. 透明边缘没有蓝边、黑边、白边或悬浮脏像素；
6. 在真实 `.app` 的小、中、大三档尺寸下，耳尖、眼睛、尾巴和脚底仍可辨；
7. 真实透明桌面窗口中，脚底基线、命中区和投喂区没有肉眼可见漂移。

第 6–7 项必须通过交互式 `pnpm qa:desktop` 由用户确认，不能只凭本目录文件记为
通过。
