# Domain Docs

说明工程技能在探索这个仓库时，应该如何读取领域文档和架构决策。

## 开始探索前优先读取

- 根目录的 `CONTEXT.md`
- 如果未来出现根目录 `CONTEXT-MAP.md`，先读它，再按需读取它指向的各个 `CONTEXT.md`
- `docs/adr/` 下与当前功能相关的 ADR

如果这些文件还不存在，技能应静默继续，不要因为缺失而中断，也不要主动要求先补齐。

## 当前文档布局

本仓库采用单上下文布局：

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

## 术语使用规则

输出中涉及领域概念时，优先使用 `CONTEXT.md` 中定义的术语，不随意改用近义词。

如果需要的术语尚未出现在 `CONTEXT.md` 中，应将其视为领域建模待补项，而不是直接发明新词。

## ADR 冲突处理

如果新的方案与已有 ADR 冲突，必须显式指出冲突，而不是静默覆盖已有决策。
