# Triage Labels

工程技能使用 5 个固定的分诊角色。这个文件定义这些角色在本仓库中的实际标签名。

| 技能角色 | 仓库标签名 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 新问题，等待维护者分诊 |
| `needs-info` | `needs-info` | 信息不足，等待补充 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可交给 agent 继续推进 |
| `ready-for-human` | `ready-for-human` | 需要人工判断、设计或实现 |
| `wontfix` | `wontfix` | 明确不处理 |

当技能提到某个分诊角色时，统一使用右侧的实际标签名。
