# macOS 预览版主线最小骨架规格

Status: accepted

## Context

当前阶段是 `macOS 预览版`，用于验证正式主线工程结构、宠物包链路、基础互动和最低恢复能力，不等于双平台 `外部 Alpha`。本规格整理既有决策和当前验收边界，不追认已经发生的实施过程符合后来补充的工程流程。

## Goals

- 从仓库根目录通过唯一主线命令启动 Tauri 桌面应用。
- 加载并校验一个声明式示例宠物包，在预览工作台显示摘要和最小行为时间线。
- 提供不依赖预览工作台持续可交互的恢复入口。
- 让用户无需终端即可隐藏、恢复、重置窗口、关闭点击穿透、重新加载示例宠物包和导出诊断摘要。

## Non-goals

- Windows 适配与 Windows 11 实机验收。
- 正式签名、公证、安装包和外部分发。
- 自动更新、完整权限引导和持续遥测后端。
- 多宠物、完整首发动画内容和复杂设置系统。
- 解决 macOS 菜单栏被其他状态项或刘海遮挡的所有系统级布局情形。

## Behavior requirements

### Preview workbench

- 启动后显示 macOS 预览工作台。
- 工作台显示示例宠物包的标识、版本、动作数、画布和校验状态。
- 用户可运行最小行为时间线并观察当前语义动作变化。
- 无边框窗口提供可识别、可操作的专用拖动入口。

### Hide and restore

- 点击工作台右上角“收起”后，预览工作台立即隐藏，应用继续运行。
- 工作台按钮与菜单栏操作必须复用 Rust 桌宠壳的同一窗口隐藏行为，不能形成两个结果不一致的路径。
- 隐藏失败时，工作台显示可理解的错误状态，不能静默无响应。
- 菜单栏入口独立于预览工作台存在；其可见时，用户可恢复已隐藏的工作台。
- 菜单栏入口被系统布局遮挡属于已知平台限制，但不能被描述为入口没有创建。

### Recovery controls

- `重置位置` 把工作台移动到当前显示器右下安全区域并显示。
- `关闭点击穿透` 可从独立菜单栏入口执行。
- `重新加载示例宠物包` 再次执行 Rust 校验，并在界面反馈结果。
- `导出诊断摘要` 把本地 Markdown 写入应用日志目录，不自动上传。

### Platform constraint

- 整窗点击穿透与系统级文件拖放不能同时工作。
- 点击穿透默认关闭；开启后必须保留独立恢复路径。

## Acceptance criteria

- `pnpm dev` 完成 `Vite -> cargo run -> Tauri` 启动链路。
- 自动化测试、格式检查、lint 和前端构建通过。
- 人工验证工作台启动、宠物包摘要、行为时间线和 PixiJS 预览。
- 人工验证拖动、收起、菜单栏恢复、重置位置和关闭点击穿透。
- 人工验证示例宠物包重新加载和诊断摘要导出。
- 完成 Standards + Spec 双轴 review，并处理阻塞性发现。
- 使用中文提交信息形成可追溯提交，并把验证、review 和提交记录写回实施 ticket。
