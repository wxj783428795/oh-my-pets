# 恢复 macOS 菜单栏入口

Type: bug
Status: claimed

## What happened

启动 macOS 预览版主线后，系统菜单栏中没有出现预期的“卷”图标，因而无法从菜单栏访问桌宠壳的恢复操作。

## What I expected

主线运行期间，macOS 菜单栏常驻一个可识别的“卷”图标，并提供“显示预览工作台”等恢复操作。

## Steps to reproduce

1. 从仓库根目录启动 macOS 预览版主线。
2. 等待预览工作台正常出现。
3. 检查 macOS 菜单栏。
4. 观察不到“卷”图标或对应的桌宠壳菜单入口。

## Additional context

- 2026-07-28 本地人工 QA 中稳定复现。
- 因入口不存在，尚无法验证“显示预览工作台”菜单项。
- 本缺陷阻塞 Issue 08 的菜单栏召回人工验收。

## Completion criteria

- 主线运行期间，macOS 菜单栏显示可识别的常驻入口。
- 菜单中存在“显示预览工作台”，并能恢复已隐藏的窗口。
- 先确认公共测试 seam，并按 `red -> green` 补充回归测试。
- 自动化验证与本地人工复验均通过。

## Answer

菜单栏入口实际已经由桌宠壳创建；首次验收时，当前内建屏幕右侧状态项过多，入口被排到中央刘海遮挡区，因而不可见也不可点击。释放菜单栏空间并重启后，入口移动到可见区域；用户已确认可以打开菜单、执行隐藏，并在窗口隐藏后左键召回预览工作台。

本票没有修改产品代码。根据已确认规格，“解决菜单栏被其他状态项或刘海遮挡的所有系统级布局情形”不在当前最小主线范围；该情形作为平台限制记录，不再阻塞 Issue 08。
