# 定义 P0 陪伴循环与必备交互

Type: grilling
Status: resolved

## Question

P0 中什么样的最小陪伴循环能让用户在首次使用、日常挂机和主动互动时都明确感到宠物“活着”？请锁定必备动作、状态、触发方式和不进入 P0 的交互，并给出可验证的体验成功标准。

## Comments

- 核心价值：宠物经常做出有趣动作。
- 触发原则：自主行为为主，用户交互触发为辅；用户不操作时也能获得乐趣。
- 打扰边界：只吸引注意，不打断工作；默认不播放声音、不抢焦点、不发送系统通知，也不长期遮挡屏幕核心区域。
- 感知边界：只读取鼠标、点击、拖拽、屏幕边缘、空闲时长和前后台状态等通用桌面信号，不读取应用内容。
- 行为规模：P0 制作 6–8 组高完成度行为，覆盖基础状态与交互，并包含 1–2 个低概率的招牌搞笑动作。
- 边缘范围：P0 正式支持每块显示器可用区域的上下左右边缘；当前前台窗口上沿只进入样机验证，不纳入 Alpha 验收；所有窗口边缘留到 P1，应用内部元素不做。
- 默认节奏：启动后 60 秒内出现一次明显动作；此后每 3–8 分钟随机出现一次趣味动作；招牌稀有动作每 15–30 分钟最多出现一次；全屏或长时间无操作时自动降频。
- 行为清单：待机观察、自主移动、休息睡觉、点击反馈、拖拽反馈、鼠标好奇、屏幕边缘玩耍，以及包含 1–2 个动作的招牌搞笑行为。
- 状态模型：P0 不显示饥饿、心情、好感度等养成数值，不设置喂养压力或离线惩罚；内部只使用平静、好奇、活跃、困倦四种临时行为状态。
- 文件拖放：P0 支持把文件拖给宠物触发无副作用的搞笑反应；不读取文件内容，不复制、移动或删除文件，不记录路径，也不改变养成数值。
- 核心成功信号：外部用户试用 3 天后仍愿意保持宠物运行，并认为它有趣但不打扰；主动录屏或分享是加分信号，不是唯一标准。
- 拖拽物理：松手后宠物继承释放方向和速度，短距离抛出并受重力落到底部；碰到边缘可反弹或短暂抓住边缘，且必须保证不会永久离开可见区域。
- 活动区域：普通行为只在屏幕边缘活动；低频招牌动作可进入屏幕中央但不超过 3 秒，并保持点击穿透。检测到全屏窗口时保留边缘活动但自动降频并禁止进入中央；会议或演示依靠用户手动开启安静模式。
- 用户控制：P0 提供安静模式与隐藏宠物；安静模式让宠物回到底部角落休息并停止自主动作，隐藏后可从托盘或菜单栏恢复。不加入番茄钟、专注统计、提醒任务或复杂排程。
- 声音边界：P0 不制作或播放音效，不提供音量设置；所有状态和互动反馈仅通过动画表达，但动作模型必须允许未来在指定时点挂接可选音效。
- 最小设置：宠物尺寸提供小、中、大；活跃程度提供安静、正常、活跃；另有点击穿透、默认关闭的开机启动、重置位置，以及隐藏或退出。不提供逐动作开关、概率或物理参数。
- 首次启动：不使用弹窗向导；宠物在 15 秒内完成入场、落地和一次招牌动作，再用自动消失的提示说明点击、拖拽及托盘或菜单栏入口。
- 隐私边界：不读取应用名称、窗口内容、摄像头或麦克风状态来识别会议或演示。

## Answer

P0 的核心价值是“宠物即使无人操作，也会经常做出有趣动作”。它采用低负担陪伴路线，不加入养成数值、离线惩罚、效率工具或音效。

- 首发包含待机、自主移动、休息、点击、宠物拖拽、鼠标好奇、屏幕边缘和招牌搞笑动作八组行为。
- 首次 60 秒内出现一次明显动作，此后每 3–8 分钟随机出现一次趣味动作；全屏时自动降频。
- 用户可点击、拖拽和抛出宠物，也可拖入文件触发无副作用反应；文件内容不读取，文件本身不修改。
- 日常活动限定在屏幕边缘；招牌动作可进入中央最多 3 秒并保持点击穿透。应用窗口边缘只进入样机验证。
- 内部只使用平静、好奇、活跃、困倦四种临时状态。P0 无声音，但动作模型为未来音效保留通用提示点。
- P0 提供尺寸、活跃程度、点击穿透、开机启动、重置位置、安静、隐藏和退出控制。
- 首次启动采用 15 秒场景化引导；成功标准是外部用户试用 3 天后仍愿意保持宠物运行，并认为它有趣但不打扰。
