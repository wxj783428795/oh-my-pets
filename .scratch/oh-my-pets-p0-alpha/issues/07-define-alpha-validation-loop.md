# 设计外部 Alpha 的验证与反馈闭环

Type: grilling
Status: resolved
Blocked by: 05, 06

## Question

在不引入账号、云同步和持续遥测后端的前提下，如何招募、引导和观察首批外部用户，并验证安装成功率、互动理解度、短期留存意愿、分享冲动和故障恢复能力？请明确样本、任务、指标、反馈渠道和继续或停止的门槛。

## Comments

- 已确认不建设观测后端；计划招募 10–20 名外部用户，第 3 天全部完成约 2 分钟问卷，并选择约 5 人进行 15 分钟访谈。
- 客户端可在本地汇总运行时长、启动次数、崩溃次数、动作与交互次数；仅在用户主动选择后导出诊断摘要，不自动上传。
- 2026-07-28 由于当前只有 macOS 环境，验证闭环也必须按阶段执行：先做 `macOS 预览版` 小规模试用，再在拿到 Windows 11 机器或测试者后扩展到真正的 `外部 Alpha`。

## Answer

验证闭环同样分两段设计，避免把“当前可测的内容”和“最终双平台目标”混在一起。

1. 阶段与样本

- `macOS 预览版`：
  - 招募 `8–12` 名 macOS 14+ Apple Silicon 用户
  - 至少覆盖这几类人：
    - `2` 名非开发者
    - `2` 名双显示器用户
    - `2` 名经常全屏或开会的用户
    - `2` 名会主动截图或录屏分享软件的用户
- `外部 Alpha`：
  - 在 `macOS 预览版` 达标后，再扩展到 `12–20` 人
  - 其中必须包含 `5–8` 名 Windows 11 用户
  - Windows 用户样本里至少有 `2` 人使用混合 DPI 或多显示器

2. 用户任务设计

每位测试者都走同一套任务，不靠自由发挥。

- 第 0 天，首次启动任务：
  - 安装应用
  - 启动并看到宠物入场
  - 完成一次点击反馈
  - 完成一次拖拽和松手下落
  - 拖入一个文件触发文件投喂
  - 打开安静模式
  - 隐藏并恢复宠物
  - 执行一次 `重置位置`
- 第 1–3 天，日常挂机任务：
  - 至少保留应用运行 `2` 个独立工作时段
  - 至少记录 `1` 次“有趣”时刻和 `1` 次“打扰”或“不懂”的时刻
- 第 3 天，收尾任务：
  - 导出诊断包
  - 回答固定的 `2` 分钟问卷
  - 其中约 `5` 人接受 `15` 分钟访谈

3. 收集方式

- 应用内只做本地统计，不接入账号或持续遥测。
- 用户主动提交的材料只有三类：
  - `诊断包`
  - 固定问卷回答
  - 可选截图、录屏或访谈记录
- 反馈渠道统一使用人工渠道，不引入产品后端：
  - 邮件
  - 即时通讯
  - 访谈通话

4. 本地指标

客户端在本地汇总这些数据，并只在用户导出时打包：

- 启动次数
- 总运行时长
- 崩溃次数
- 安全恢复次数
- 点击次数
- 拖拽次数
- 文件投喂次数
- 安静模式切换次数
- 隐藏与恢复次数
- 最近错误码与关键日志

5. 判断指标

`macOS 预览版` 是否继续推进，看下面这组门槛：

- 安装成功率：至少 `80%` 的用户无需人工远程协助即可完成安装和首次启动。
- 互动理解度：至少 `75%` 的用户能在首次 15 分钟内自己发现点击、拖拽、安静模式和隐藏/恢复入口。
- 短期留存意愿：至少 `60%` 的用户在第 3 天表示愿意继续保留它至少一周。
- 分享冲动：至少 `30%` 的用户主动发送截图、录屏，或明确表示“愿意分享给朋友”。
- 恢复能力：涉及宠物丢失、黑屏、点不到宠物、不会退出这几类问题时，`100%` 必须能仅靠应用内入口恢复，不允许靠终端或手删配置。
- 打扰边界：认为“明显打扰工作”的用户不得超过 `20%`。

`外部 Alpha` 的继续门槛在此基础上再加一层：

- Windows 11 用户完成与 macOS 同样的首次启动任务和 3 天挂机任务。
- Windows 用户中至少 `80%` 能顺利安装、恢复和卸载。
- 没有集中爆发的 DPI、多显示器、托盘恢复或透明窗命中测试故障。

6. 停止或回炉信号

出现以下任一情况，就不进入下一阶段，而是先回炉修正：

- 安装成功率低于 `60%`
- 超过 `20%` 的用户在 3 天内主动关闭并不愿再打开
- 出现任何需要终端、删配置或人工远程接管才能恢复的故障
- 多名用户误以为文件投喂会读取、上传或修改文件内容
- 几乎没有人能描述出一段“招牌动作”或记住宠物个性，说明内容本身不成立

7. 阶段出口

- `macOS 预览版 -> 外部 Alpha` 的出口条件：
  - `Issue 05` 的发布与恢复门槛达标
  - `Issue 06` 的首发宠物内容在试用里被理解并记住
  - 已拿到 Windows 11 机器或外部测试者
- 如果 Windows 条件仍未具备，允许继续迭代 `macOS 预览版`，但不允许把它重新命名成“正式外部 Alpha”。

结论是：当前最可执行的验证闭环不是一次性招募 10–20 名双平台用户，而是先用 `8–12` 名 macOS 用户完成一轮严格的 `预览版` 验证，确认安装、互动、恢复和分享性成立后，再补 Windows 11 样本进入真正的 `外部 Alpha`。
