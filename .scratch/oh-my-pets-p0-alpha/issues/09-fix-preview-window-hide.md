# 修复预览工作台无法收起

Type: bug
Status: claimed

## What happened

在 macOS 预览版主线窗口中点击右上角“收起”后，窗口没有隐藏，也没有可见状态变化。

## What I expected

点击“收起”后，预览工作台立即从桌面隐藏，并可通过独立的菜单栏入口重新显示。

## Steps to reproduce

1. 从仓库根目录启动 macOS 预览版主线。
2. 等待预览工作台正常出现。
3. 点击右上角“收起”。
4. 观察预览工作台仍然可见。

- 窗口拖动与重置位置均已验证可用。
- 本缺陷阻塞 Issue 08 的窗口恢复人工验收。
